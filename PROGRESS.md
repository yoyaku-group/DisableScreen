## ADR 023 — Session de maintien éveillé minutée (2026-11-06)

Jusqu'ici l'interrupteur n'avait pas d'heure de fin : la seule protection contre un oubli était la garde batterie. Une session donne une échéance au flag, visible dans la barre des menus, appliquée par le tick qui possède déjà le flag.

- DONE — `RunClosedCore/KeepAwakeSession.swift` : record `{ id, startedAt, endsAtWall, endsAtContinuous, bootID, pausedReason, schemaVersion }`. `endsAt` nul = session indéfinie, soit l'interrupteur simple d'aujourd'hui, sans changement de comportement. Décodage tolérant : une clé ajoutée plus tard (backstop L2, actions capot L4) ne fait pas passer un fichier valide pour corrompu.
- DONE — `RunClosedCore/ContinuousClock.swift` : `mach_continuous_time` converti par `mach_timebase_info` (timebase lu une fois). Distinct de `SystemClock.systemUptime`, qui **s'arrête pendant la veille** (`Clock.swift:14-17`) — précisément la fenêtre d'usage. Injectable pour les tests.
- DONE — `RunClosedCore/SessionPolicy.swift` : politique pure. Dû si le compteur continu dépasse l'échéance **sur le même boot**, ou si l'horloge murale la dépasse (seule source valable après un reboot). Refus de démarrer une session minutée quand le flag est ON mais non possédé (l'expiration échouerait en `notOwned`). Extension depuis maintenant, pause/reprise, libellés. `SessionDuration.parse` : `2h`, `90m`, `1h30m`, `1h30`, nombre nu = minutes.
- DONE — `RunClosedPersistence/SessionStore.swift` : `session.json`, `.atomic`, `schemaVersion`, fichier absent ou corrompu = aucune session. Accepte la forme nue et la forme enveloppée (`{schemaVersion, session}`), la forme nue essayée d'abord.
- DONE — `RunClosedMacSystem/LidMutationService.swift` : initiateur `.sessionRecovery(bootID:)` + `mayRelease` pure. Il n'admet que NOTRE record **du boot de la session** ; tout autre record périmé reste refusé (ADR 015 conservé), `.automatic` compris.
- DONE — `RunClosedMacSystem/SessionService.swift` : journal avant effet (record écrit avant le flag, supprimé si le flag échoue), démarrage/adoption d'un flag déjà ON possédé, extension, End, `expireIfDue`, pause batterie, reprise, `allowsRearm`. - DONE — `RunClosedMacSystem/LowBatteryGuardService.swift` : `sessionService` optionnel.
